# Portfolio Data Analyst — Eddy Michel Leukeu Nkombou

Portfolio web statique basé sur le CV fourni.

## Déploiement GitHub Pages

1. Créer un dépôt public sur GitHub, par exemple `portfolio-data-analyst`.
2. Mettre `index.html`, `style.css` et le PDF du CV à la racine du dépôt.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**.
4. Sélectionner la branche `main` et le dossier `/ (root)`.
5. Enregistrer. GitHub Pages fournira l'URL du site.

## À personnaliser

- Remplacer les liens `https://github.com/` par le vrai profil GitHub.
- Ajouter les vrais dépôts dans la section Projets.
- Ajouter des captures de dashboards Power BI si disponibles.
